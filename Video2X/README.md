# Video2X — Free AI Video Super-Resolution

This folder documents how to run Video2X for AI upscaling without paying for a subscription.

## Official project

- Source: https://github.com/k4yt3x/video2x
- Documentation: https://docs.video2x.org/
- Official free Google Colab notebook: https://colab.research.google.com/drive/1gWEwcA9y57EsxwOjmLNmNMXPsafw0kGo

Video2X supports AI upscaling with Real-ESRGAN and Real-CUGAN, plus frame interpolation with RIFE. It runs on Windows and Linux and requires a Vulkan-capable GPU for the prebuilt desktop builds.

## Run it for free in Google Colab

1. Open the official Colab notebook linked above.
2. Sign in to Google.
3. In Colab, choose **Runtime → Change runtime type → T4 GPU** if a free GPU is offered.
4. Run the notebook cells in order and upload your source video when prompted.
5. Download the processed output from the notebook.

Free GPU availability and session limits are controlled by Google and are not guaranteed. Do not assume unlimited processing time.

## Important

This GitHub folder is a setup guide, not an installed copy of Video2X. GitHub repositories store source code and documentation; the actual program runs on a computer or a cloud runtime such as Google Colab.

For the latest installation instructions and releases, always use the official Video2X repository linked above.
