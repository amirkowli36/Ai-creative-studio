# Face and identity preservation

This area is for workflows that preserve a consenting subject's identity while changing style, lighting, clothing, background or other scene details.

Candidate approaches may include reference-image adapters or identity-conditioning nodes such as PuLID or InstantID. Compatibility, node availability, model licenses and GPU memory requirements must be checked for each specific workflow before it is selected.

Every workflow must document:

- Required custom nodes and exact tested versions
- Model files and licenses
- How the reference image is prepared
- Which settings affect identity strength and composition
- Known limitations, including cases where identity can drift

Use reference images only when you have permission from the people depicted. Do not use these workflows to impersonate someone or create deceptive material.
