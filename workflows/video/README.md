# Video generation

This area is for image-to-video and text-to-video workflows.

Before committing a workflow, record:

- Model and version
- Required custom nodes
- Resolution, frame count and frame rate
- GPU memory requirements and tested runtime
- Whether the workflow supports image conditioning, camera motion or temporal controls
- Model license and any usage restrictions

Video generation is substantially more resource-intensive than still-image generation. Do not assume a free Colab GPU can run every model or resolution.
